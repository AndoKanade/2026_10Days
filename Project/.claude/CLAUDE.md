# 現在の実装目標：ローダーと配置（01_12）
- 目的：Blenderで自作した任意のモデル（球やBoxなどBlender標準のデフォルト形状は不可。例：地面、ビルなど自作モデル）を複数配置し、その配置情報をBlenderから出力、ゲーム画面側でも同じ配置を再現できるようにする。
  - （ゲーム制作にエディタとして活用する上での最低限の機能という位置づけ）
- 必須条件（すべて満たすこと）：
  1. 複数種類のモデルをインポートして配置できていること。
  2. Blender側とゲーム側で、各モデルの位置・回転が一致していること。
  3. 配置情報をリアルタイムに変更し、再読み込み（ホットリロード）した際にゲーム側へ即座に反映されること。
- 実装時の注意：
  - Blenderからの出力データ（位置・回転・使用モデル名など）のフォーマットを明確に定義し、パース処理は上記コーディング規約（マジックナンバー禁止・定数化）に従うこと。
  - 将来的な+α実装（コライダー適用、SpawnPoint配置、イベントトリガー配置、ギミック配置、カメラ配置、敵巡回ルート、Terrain配置、メッシュシンクなど）を見据え、モデル種別ごとに拡張しやすい設計にすること。
